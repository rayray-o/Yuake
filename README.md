#YUAKÉ

YUAKÉ is a browser-based camera interaction experiment.

## Stack

- Next.js
- React
- TypeScript
- MediaPipe Tasks Vision
- GPU Hand Landmarker
- Two-hand tracking
- One-Euro adaptive filtering
- Scale-normalized hand geometry
- Pinch hysteresis
- Per-finger touch hysteresis
